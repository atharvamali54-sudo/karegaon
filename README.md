## 🔑 मुख्य फीचर्स:

### १. भाडेकरू पोर्टल (Tenant Portal):
- रूम नंबर निवडताच चालू महिन्याचे बिल दिसते:
  - **खोली भाडे:** (सिंगल ₹३,००० / डबल ₹५,०००)
  - **लाईट बिल:** मागील रिडिंग व चालू रिडिंगमधील फरक × ₹१०/युनिट
  - **पहिली बाकी:** मागील महिन्याची थकबाकी
  - **एकूण भरायची रक्कम:** (भाडे + लाईट बिल + बाकी)
- **UPI QR कोड:** Google Pay, PhonePe, Paytm ने थेट स्कॅन करून पेमेंट करता येते.
- **UTR नोंदवणे:** पेमेंट झाल्यावर १२ अंकी UTR नंबर सबमिट करता येतो.
- **Payment Successful & पावती:** मालकाने व्हेरिफाय केल्यावर लगेच 'Payment Successful' दिसेल आणि अधिकृत डिजिटल पावती (Receipt) डाउनलोड / प्रिंट करता येईल.
